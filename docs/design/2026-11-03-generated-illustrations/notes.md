# Generated marketing illustrations

User direction: retain the authentic platform screenshot only in the homepage hero; use custom generated illustrations everywhere else in marketing. Make the hero grid gray, more visible and animated.

Four original image-generation assets live in apps/marketing/public/illustrations: preparation, attachment, relations and publication. They explain draft preparation, attached PDF and data, linked records, and availability to citizens. They are conceptual artwork, not screenshots or claims of additional functionality. The image framing excludes the redundant generated wordmarks; the actual site logo stays unchanged. The original generated files are preserved.

Hero motion: a 64px gray grid moves diagonally by one cell over 16 seconds. Pause/resume is available; IntersectionObserver and page visibility pause work outside the visible hero. Reduced-motion disables the animation. No new dependencies.

The same artwork is used consistently in benefits, about, editorial links, workflow tabs and demo role choices. Only the homepage hero retains /previews/office-overview.png. Citizen and officer portals and database contents are unchanged.
