# MetaFi → OpenObec: rozbor a obsahová stratégia

Autorita: používateľ zvolil MetaFi a schválil prerábku marketingu. Verejné referencie: [MetaFi](https://metafi-nextjs-template.vercel.app/), [katalóg shadcnblocks](https://www.shadcnblocks.com/blocks). Nejde o prevzatie plateného zdrojového kódu. Snímky v `reference/` sú porovnávacie dôkazy, nie produkčné obrázky OpenObec.

## Čo nesie podobnosť

- Úzky, pokojný header s logom vľavo, navigáciou uprostred a akciami vpravo. Predajný banner šablóny sa do produktu neprenáša.
- Inter, na desktope 68 px úvodný nadpis a na mobile 36 px; kontaktný mobilný nadpis 30 px. Takmer čierny text a tlačidlá, biela plocha, fialové akcenty.
- Centrovaný úvod s veľkými medzerami a dvomi akciami; za produktovým náhľadom miznúca pravidelná mriežka. Dôležitá je skutočná obrazovka aplikácie.
- Približne 1152 px obsahová šírka pri 1440 px, jemné obrysy a malé tiene. Obsah sekcií má rozdielnu hustotu, rovnakú typografickú hierarchiu.
- Fialové záverečné CTA s mriežkou a výrazne tmavá päta. Tmavý režim používa uhlové modrosivé plochy, nie pôvodnú sýtu IDSK modrú.
- Features je dvojstĺpcový úvod, about centrovaný úvod s panoramatickou fotografiou, pricing dvojica širokých ponúk a porovnanie, contact centrovaný panel prekrývajúci jemne sivú plochu. Nestačí všetkým stránkam dať rovnakú mriežku kariet.

## Ako predať produkt úradníkovi

Návštevník rieši konkrétny dokument, nie architektúru softvéru. Prvá obrazovka musí ukázať, že vie dokument pripraviť, priložiť PDF a zverejniť. Následné sekcie odpovedajú na otázky: kde sú koncepty, ako doplním prílohu, čo uvidí občan, ako nájdem súvisiacu zmluvu, či si to viem vyskúšať bez hesla.

Hlavné CTA preto vedie do pracovného portálu. Občiansky portál je dôkaz výsledku. Názvy Kafka, MongoDB a mikroslužby patria technickej dokumentácii, nie predajnému úvodu.

| Referenčná úloha | Obsah OpenObec |
| --- | --- |
| Platobný dashboard v úvode | Reálny pracovný prehľad dokumentov |
| Pás zákazníckych značiek | Šesť konkrétnych agend |
| Produktové funkcie s obrázkami | Koncept, PDF, súvislosti, publikovanie |
| Integračné dlaždice | Typy dokumentov a čo sa v nich eviduje |
| Referencie zákazníkov | Konkrétne pracovné situácie bez falošných citátov |
| Blogové ukážky | Cesty k vyskúšaniu funkčného pracovného postupu |
| Kontaktný formulár | Skutočné kontaktné možnosti projektu bez predstieraného odoslania |
| Platené plány | Otvorený kód + jasne označený plán služby 199 €/rok |

Nevkladať tvrdenia o automatickom prepojení mestského IS, garancii právnych lehôt, existujúcich klientoch ani nameranej úspore. Funkčné lokálne demo a reálne snímky sú dostupný dôkaz. O nás opisuje motiváciu a otvorenosť projektu, nie vymyslenú firmu.

## Dôkazy

CUA návštevy všetkých piatich stránok pri 1440×1000 a 390×844. Každá stránka bola prescrollovaná pred celostránkovou snímkou, aby sa zobrazili vstupné animácie. `measurements-desktop.json` a `measurements-mobile.json` zachovávajú namerané nadpisy a rozmery. Tmavý úvod je v `home-hero-dark.jpg`. Referenčné rozmery sú vodidlo; slovenský obsah musí zostať čitateľný a bez presahu.
