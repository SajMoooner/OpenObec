Reference: https://metafi-nextjs-template.vercel.app/ and the three supplied screenshots. Inspected the live light theme, hero layers and feature section in the native browser.

Direction: preserve the centered MetaFi composition, 64px neutral grid with radial edge fade, soft neutral glow, asymmetric 7/5 then 5/7 feature cards, and overlapping agenda icons. Use authentic OpenObec screenshots, not copied payment UI or invented integrations.

Motion thesis: the copy introduces the product, then the dashboard settles into place. Product details assemble once as they enter view. Finite transform/opacity and bounded 2px blur entrances; no endless loops or new animation dependency. Static content remains visible before JavaScript and when reduced motion is requested. Reduced-motion changes cancel active detail animations.

Readability: targeted crops show document fields, PDF attachment, related documents and public document information. Separate original-image links preserve full context. The benefits workflow uses distinct attachment and publication crops from the same real document. Screenshot source bytes remain unchanged.

Verification: TypeScript, scoped ESLint, production Docker build, marketing route/layout/interaction tests, demo-entry tests, native desktop/mobile screenshots and theme checks. Only marketing application source changed; no database writes or portal UI changes.
